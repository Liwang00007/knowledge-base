## 使用方法

1. **收件箱**：看到任何有价值的信息，先扔进 `00-收件箱`，别纠结分类
2. **每日清理**：下班前 5 分钟，把收件箱内容归档到对应目录
3. **双向链接**：用 `[[笔记名]]` 把零散知识点连成网
4. **问 Claude**：需要调用知识库回答客户问题时，告诉我"参考知识库里的 XX 笔记"

| 文件夹 | 放什么 |
|--------|--------|
| `00-收件箱/` | 快速记录，当天归档 |
| `01-行业研究/` | 行业分析、趋势、政策、技术科普 |
| `02-公司档案/` | 每家公司一页笔记，关键信息+追踪 |

| `05-日报周报/` | 日常工作记录 |
| `99-模板/` | 笔记模板，新建笔记时套用 |
