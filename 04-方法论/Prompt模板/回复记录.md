# 客户回复 Prompt 模板

> 类型：方法论/Prompt模板 | 来源：杭总 + 刘珈宁经验
> 用途：回复客户测试问题时直接用

## 核心原则（来自杭总）

1. **回复长度不要太长** — 客户没时间看长文
2. **回复口吻不要像新闻稿** — 要像专业人士在对话，不是念稿
3. **数据指标要有相关性** — 每个数字都要回答”对客户意味着什么”

## 标准 Prompt 模板（来自刘珈宁）

复制下面这段话，替换 `[公司名]` 和 `[问题]` 即可：

```
从[公司名]角度直接回答，150-300字以内，可以用英文简称，不要打括号，AI感弱一点，技术一点：[问题]
```

### 模板变体

| 场景 | 追加词 |
|------|--------|
| 回答要更技术向 | 加 `技术一点` |
| 回答要更商业向 | 加 `商业策略角度` |
| 要求精简 | 改字数限制为 `100-150字` |
| 不相关领域 | 加 `不相关的我会提示` |

## 已验证有效的问题回复模式

### 模式 1：三段式
- 第一句：直接结论（1 句话）
- 第二段：支持结论的关键数据/理由（2-3 句）
- 第三段：对客户业务的影响（1 句）

### 模式 2：对比式
- 客户问”A 还是 B”
- 先各一句话说清 A 和 B 的核心区别
- 再根据场景判断哪个更合适
- 给出理由
