# AI算力芯片系统：别只盯着英伟达，整块主板都在分钱

> 日期：2026-06-03
> 类型：行业研究
> 来源：坤元财研《AI算力硬件第2集：AI算力芯片系统》

## 一句话总结

全球万亿AI算力的硬件投资，超过70%流进了主板上的算力芯片系统。GPU吃肉，但HBM、ASIC、CPU、DDR5、eSSD、台积电和EDA工具都在分——每一块主板都是全球顶尖企业博弈的结果。

## 五件套：算力系统怎么运转

用视频里的工厂比喻，一块算力主板就是一座高速运转的工厂：

| 角色 | 对应硬件 | 干什么 |
|------|---------|--------|
| **工人** | GPU/ASIC | 干粗活，海量并行计算 |
| **搬运工** | HBM（高带宽存储） | 贴在GPU旁边，最快速度投喂数据 |
| **包工头** | CPU | 调度数据流、管指令 |
| **中转站** | DDR5（系统内存） | 清洗预处理数据，数据不能从硬盘直塞GPU |
| **大仓库** | eSSD（固态硬盘） | 存训练数据、向量库、知识库；还是训练宕机时的救命稻草 |

> 内存墙：GPU算太快，传统内存传太慢，HBM就是为打破这堵墙设计的。

## 算力芯片：GPU vs ASIC 的正面搏杀

### 训练和推理得分开看

| | 训练（造模型） | 推理（用模型） |
|---|---|---|
| **要求** | 极高：超大显存、极强互联 | 一般：成本低、延迟短就行 |
| **地位** | 算力金字塔顶端 | 量大面广 |

### 全球训练市场（2025年数据）

- **英伟达**：90%+，几乎垄断
- AMD：3%-5%
- Intel：不足1%
- 国内（制裁下）：英伟达仍占60%，华为昇腾25%，寒武纪5%，海光3%

一句话：国内一线大模型几乎全用英伟达GPU做训练，嘴上说不要，身体很诚实。

### 英伟达凭什么垄断训练？

三条护城河，每一条都很硬：

**1. CUDA生态——AI界的Windows**
整个行业十几年的算子、算法、工具全在CUDA里。不用CUDA？代码基本得重写，遇到bug几个月排查不出来。烧钱如流水的大模型团队根本扛不住这种时间成本。

**2. 全栈能力——不单卖GPU**
从芯片 → NVLink互联 → InfiniBand网络 → 封装 → 集群调度，一整套。单卡性能可能被追，但万卡集群的效率和稳定性目前还没对手。

**3. 迭代速度——一年一代**
别家芯片刚量产准备对标H100，英伟达下一代更牛的已经发货了。黄仁勋的逻辑：你追得够快，对手就只能一直追。

### 云厂商的反击：自研ASIC

谷歌、微软、亚马逊、Meta不甘心永远做黄仁勋的打工仔。两边出手：
- **扶持AMD**：不仅买GPU，还深度参与AMD的ROCm软件生态建设
- **自研ASIC**：联合博通、Marvell，砍掉GPU里所有不必要的通用电路，每个晶体管全用来伺候大模型

**ASIC杀伤力在哪？** 相同算力下，ASIC的成本和功耗只有同级GPU的一半。

具体案例：
- 谷歌Gemini + Claude → 用自研TPU训练和推理
- ChatGPT → 部分用微软自研Maia系列芯片

但即便如此，谷歌/微软还是得大量采购英伟达GPU——预训练研发、实验、第三方云业务仍然离不开。云厂商的战略目标是给英伟达传递一个信号：**"我们有备胎，你别太过分。"**

### 黄仁勋的反制

1. **200亿美元收购Groq**（2025年底）：Groq创始人Jonathan Ross是谷歌TPU之父，英伟达这一手补了推理端ASIC的短板，也封死了其他初创弯道超车的路。

2. **20亿美元战略投资Marvell**（2026.3）：Marvell和博通是帮云大厂造ASIC的头号幕后枪手。英伟达投资Marvell堪称釜底抽薪——"给你们造芯片的公司现在也是我的人了。你可以用自己的芯片，但Scale-up网络架构你总得用我的吧？"

### 推理市场走向

IDC预测：到2028年，ASIC在推理市场的市占率从10%提升到40%，和英伟达的差距大幅缩小。ASIC遍地开花，晶圆代工、封测、芯片设计/IP公司都会分走一块蛋糕。

## CPU：被忽视的暗战

过去两年所有人眼里只有GPU，传统CPU看起来只是配角。但现在情况变了。

**引爆点：AI Agent**

Agent不只是聊天的模型，而是能执行多步骤任务（调用工具、发邮件、订机票）的智能体。问题从"算得快不快"变成了"调度聪不聪明"——串行逻辑控制，恰恰是CPU的老本行。Agent时代，GPU/ASIC负责计算，CPU负责指挥调度，不再是主次关系。

**三股势力围剿X86：**

| 势力 | 动作 | 目标 |
|------|------|------|
| **英伟达** | 基于ARM自研Grace CPU，在NVL72里用自己的CPU配自己的GPU | 把X86从高端AI机柜里踢出去 |
| **云大厂** | 谷歌/微软/亚马逊自研ARM CPU（Graviton\Cobalt） | 摆脱X86依赖，降功耗 |
| **ARM公司** | 不仅卖IP，还推半成品计算子系统，甚至亲自下场找台积电代工卖AGI-CPU芯片 | 直接吃增量市场 |

目前格局：Intel仍占70%+，AMD约20%，ARM不到10%但增长极快。

## 存储芯片：最卡脖子的命门

### HBM——全产业链最紧缺的东西

芯片厂和云大厂最焦虑的不是买不到GPU，而是买不到HBM。

**为什么这么难造？** DRAM是典型的工艺驱动型产业——难在制造，是手艺活。工艺窗口极窄，必须靠几十年经验慢慢调，中间断一年都不行。DRAM厂商必须是IDM（自建工厂），没法像CPU/GPU那样走代工模式。

这就是为什么全球能做HBM的只有三家：

| 公司 | 份额 |
|------|------|
| SK海力士 | 57% |
| 三星 | 22% |
| 美光 | 21% |

三家垄断，全部受美国出口管制。

**国内**：长鑫存储跳过HBM2，完成HBM3样品开发，计划2026年上半年量产，良率目标80%。但主要服务国内算力生态，进不了北美市场。

### 连锁反应：产能被AI挤干

海力士和三星把70%-90%的先进DRAM产能全转去造HBM和服务器DDR5→传统内存涨价→你买电脑内存觉得贵，就是因为产能被AI大佬抢光了。

### DDR5 和 eSSD

- **DDR5**：同样三巨头（三星/海力士/美光）垄断93%，同样紧缺涨价。国内长鑫全球份额3%-5%。
- **eSSD（企业级固态硬盘）**：三星30%、海力士28%、西部数据14%、铠侠12%、美光10%。**国产进步最快**，国内市占率已达20%-25%。

### 投资避坑指南

存储涨价带飞了很多模组公司（大普微、忆恒创源、华为忆联、江波龙、佰维存储等）的业绩。但必须区分两个东西：
- 是靠囤低价晶圆颗粒赚的一次性库存差价
- 还是靠自研主控芯片 + 自研固件算法的真本事

**两条判断标准**：
1. 有没有自研企业级主控芯片和复杂固件算法的能力
2. 产品有没有实打实进了阿里、字节、腾讯等一线云大厂的核心算力机柜

跨不过这两道门槛的，大概率只是在吃周期红利。

## 隐形收税人：台积电、EDA、ARM

不管谁赢，以下几家公司永远在抽成：

| 环节 | 代表公司 | 逻辑 |
|------|---------|------|
| **EDA+IP** | Synopsys、Cadence、ARM | 自研ASIC不是从零造轮子——设计必须用EDA软件，CPU可能得买ARM授权 |
| **晶圆代工** | 台积电 | 3nm/2nm高端芯片的唯一去处。台积电不参与竞争，它就是竞争本身 |
| **先进封测** | 台积电（CoWoS）、日月光 | HBM必须紧贴GPU精准封装，靠的就是CoWoS |

## 对我的价值

- 客户问"AI产业链除了英伟达还能聊什么"：五件套框架 + CUDA三条护城河 + ASIC反击 + CPU暗战 + HBM命门，每个都能展开讲透
- 存储板块避坑要看两点：有无自研主控 + 有无进大厂机柜，不是看财报涨了多少
- ASIC推理市场规模到2028年从10%→40%，这个趋势值得持续跟踪
- 台积电、Synopsys、ARM是"卖铲人的卖铲人"，波动小、确定性高
