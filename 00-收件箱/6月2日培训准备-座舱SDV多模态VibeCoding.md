## 一、智能座舱（核心话题）

### 一句话开场
> "2026 是大模型批量上车元年。座舱竞争从'堆配置'变成了'拼 AI 体验'。"

### 核心数据（记住 3 个数字）

| 数据         | 数值                 |
| ---------- | ------------------ |
| 智能座舱渗透率    | 83%（新能源 94.5%）     |
| 座舱域控架构渗透率  | 突破 50%，同比 +15 个百分点 |
| 2030 年市场规模 | 3300 亿元            |

### 核心变化：从"被动听指令"到"主动办事情"

- **过去**：语音助手 = 填槽式，"打开空调""导航到 XX"
- **现在**：AI Agent = 理解需求 + 主动服务，"检测后排孩子睡着 → 自动调温 + 关窗 + 放轻音乐"

### 主要玩家速查

| 玩家 | 方案 | 装机量 |
|------|------|--------|
| 火山引擎（字节） | 豆包座舱助手 | 700 万+ 辆车，145 款车型 |
| 华为 | HarmonySpace 6 + 小艺 | 问界 M9 首发，千亿参数 |
| 阿里 | 千问智能体 | 10+ 车企（长安/东风/比亚迪/吉利/理想） |
| 腾讯 | 出行全场景智能体 | 微信生态 + 小程序支付 |
| DeepSeek | 轻量化模型 | 比亚迪璇玑架构 + 特斯拉中国 |

### 关键趋势

1. **Agent 化**：AI 从"执行命令"到"理解需求、主动服务"
2. **舱驾一体**：智舱 + 智驾芯片融合，地平线星空（5nm/650TOPS）、高通 8797
3. **端侧部署**：云端 Token 按次计费不可持续，端侧推理是趋势
4. **多模态感知**：舱内摄像头 + 红外 + 传感器 → 全方位感知

### 金句引用
> 零跑朱江明："未来两三年，智能化能力将决定企业生死。"
> 吉利李传海："技术远未到收敛期，汽车才是智能的最佳载体。"

## 二、SDV 软件定义汽车

### 一句话开场
> "SDV 就是让车像手机一样，买回去之后还能通过软件升级获得新功能。2026 年从概念验证进入了规模化量产。"

### 架构演进：5 个层级

| Level | 能力 | 行业现状 |
|-------|------|---------|
| L0 | 无联网，纯机械 | 已淘汰 |
| L1 | 基础联网 | ✅ 主流 |
| L2 | OTA 维护更新 | ✅ 主流 |
| L3 | 可推送新功能到单一车系 | ✅ 头部车企 |
| L4 | 全世代车型 + 第三方功能 | 🔄 进行中 |
| L5 | 开放创新平台 | 🔮 未来 |

→ 当前行业主流：L2-L3，快速迈向 L4

### 关键趋势

1. **从功能域 → 区域架构**：按物理位置（非功能）组织电子，100+ ECU → 中央计算
2. **Right-sized SDV**：座舱/车身域灵活升级，自动驾驶域高可靠，边缘节点成本固化
3. **云原生开发**：虚拟 SoC、云端全流程验证，"Everything as Code"
4. **从 SDV 到 AIDV**：一汽红旗提出"AI 定义汽车"，座舱从被动响应 → 主动服务

### 核心玩家

| 玩家 | 方案 |
|------|------|
| 高通 | 骁龙数字底盘 + 虚拟 SoC，零跑 D19 首发双 8797 |
| NXP | CoreRide Z248 区域架构参考系统 |
| Elektrobit | Right-sized SDV + 语义 API，50-60% 效率提升 |
| HARMAN | Ready CQuence 工具链，8000 万+ 车 OTA |
| 伟世通+英伟达 | 边缘-云 AI 仲裁架构 |

### 金句
> "SDV 的核心不是软件，是'软硬件完全解耦'——硬件造好之后，软件还能持续进化。"

## 三、多模态 AI

### 一句话开场
> "多模态就是 AI 不仅能读文字，还能看懂图、听懂声音、生成视频。2026 年最大的变化是——从'拼接式多模态'变成了'原生统一多模态'。"

### 核心突破

| 过去（拼接式） | 现在（原生统一） |
|------|------|
| 文本模型 + 图像模型 + 视频模型分别训练再拼一起 | 一个统一基座，所有模态一起训练 |
| 模态间转换损失大 | 跨模态知识迁移，端到端原生理解 |
| 代表：GPT-4 + DALL-E 分开 | 代表：Gemini Omni Flash、文心 5.0 |

### 核心数据

| 指标            | 数值                    |
| ------------- | --------------------- |
| 原生全模态模型参数量    | 3970 亿（动态稀疏，仅激活 5.7%） |
| 上下文窗口         | 128K → 100 万 token    |
| OpenAI ARR    | >250 亿美元              |
| Anthropic ARR | >440 亿美元              |
| Minimax 视频生成  | 累计超 6 亿个              |
| VEO 视频生成      | 半年突破 2.3 亿条           |

### 应用场景

| 领域 | 应用 | 效果 |
|------|------|------|
| 工业质检 | 图像缺陷 + 设备日志联合分析 | 检出率 99.7% |
| 智能客服 | 文本 + 语音情绪 + 视频肢体 | 解决率 58% → 79% |
| 医疗 | CT + 病历 + 化验报告 | 肺结节 F1=0.87 |
| 金融 | 交易文本 + 行为视频 + 语音 | 反欺诈 |
| 教育 | 讲课视频 → 知识点图谱 + 教材 | 全自动 |
| 内容创作 | AI 短剧、AI 电影 | 已获龙标上映 |

### 金句
> "多模态模型的商业上限远超纯文本模型——这是 AI 行业最大的视野盲区。"

## 四、Vibe Coding（备选话题，开场用）

### 一句话开场
> "Vibe Coding 就是用大白话跟 AI 说'我要做个什么'，AI 帮你把代码全写了。2026 年，一个零编程基础的经济学毕业生用 Cursor 一小时做出了 App Store 前 20 的应用。"

### 概念

Andrej Karpathy（OpenAI 联合创始人）2025 年提出：
> "你完全沉浸于感觉，忘记代码的存在。"

- 传统编程：逐行写代码，关注"怎么做"
- Vibe Coding：自然语言描述意图，AI 生成代码，关注"做什么"

### 主流工具

| 工具                     | 定位            | 适合谁  |
| ---------------------- | ------------- | ---- |
| **Cursor**             | AI 原生 IDE（龙头） | 专业开发 |
| **Windsurf**           | 自主意识 IDE      | 复杂逻辑 |
| **Replit Agent**       | 网页即开即用        | 零基础  |
| **Claude Code**        | 终端 Agent      | 你正在用 |
| **Bolt.new / Lovable** | Prompt 生成前端   | 快速原型 |

### ⚠️ 必须讲的风险

> Cursor CEO 亲自泼冷水：他让 AI 写了 300 万行代码复刻浏览器，结果连 Google 首页都加载不了。

**五大死法**：
1. 隐蔽 Bug（看起来对，其实是错的）
2. 安全隐患（硬编码密码、SQL 注入）
3. 幻觉依赖（AI 虚构包名，攻击者注册恶意包）
4. 架构债务（Agent 各自为战，代码库越来越乱）
5. 死亡螺旋（把错误喂给 AI → AI 反刍新错误 → 无限递归）

**铁律**：永远循环（写-测-跑-修）、必须有测试、强制安全检查、涉钱涉密必须人工审。
