# Transformer 架构详解 — 从 Attention 到大模型基石

## 一句话总结

> 2017 年《Attention Is All You Need》提出的 Transformer 架构，用纯注意力机制替代了 RNN 的串行结构，成为 GPT、DeepSeek 等所有大语言模型的技术起点。

## 一、为什么这篇论文重要

2017 年，Google 的八位作者发表《Attention Is All You Need》，标题就是在宣告：**抛弃 RNN / CNN，只用 Attention 就够了。**

| 时间线 | 事件 |
|--------|------|
| 2017.06 | Transformer 论文发表 |

## 二、Token 与向量：文本变成数字

### 2.1 Token 切分

```
输入文本: "我爱吃苹果"
    ↓ 分词器（Tokenizer）
Token:  ["我", "爱", "吃", "苹果"]
```

不同模型用不同分词策略（BPE / WordPiece / SentencePiece）。

### 2.2 Embedding：Token → 语义向量

每个 Token 被映射为一个稠密向量（例如 768 维或 4096 维），携带语义信息：

```
"苹果" → [0.23, -0.51, 0.78, ..., 0.12]
```

语义相近的词，向量距离也近（如"苹果"和"香蕉"比"苹果"和"汽车"更近）。

### 2.3 位置编码（Positional Encoding）

> Attention 本身看不到语序 → 必须注入位置信息。

```
"狗 咬 人" vs "人 咬 狗"  → Token 完全一样，意思完全不同
                                  ↓
                        位置编码区分语序
```

用正弦/余弦函数生成位置向量，加到 Embedding 上：

```
最终输入 = Embedding + 位置编码
```

## 三、QKV 与注意力：核心计算

### 3.1 三个矩阵

| 符号 | 全称 | 含义 | 类比 |
|------|------|------|------|
| **Q**（Query） | 查询 | 「我要找什么」 | 你在搜索框打的字 |
| **K**（Key） | 键 | 「我是谁，来匹配我」 | 文章标题 |
| **V**（Value） | 值 | 「我的实际内容」 | 文章正文 |

### 3.2 怎么来的

同一个输入 X，乘以三个可训练矩阵：

```
Q = X × W_Q
K = X × W_K
V = X × W_V
```

### 3.3 计算过程

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

| 步骤 | 操作 | 含义 |
|------|------|------|
| ① | `Q × K^T` | Q 遍历所有 K，算出每个词对其它词的**相关度分数** |
| ② | `÷ √d_k` | **缩放**，防止分数过大导致梯度消失 |
| ③ | `softmax(...)` | 分数转为 **0~1 权重**，总和为 1 |
| ④ | `× V` | 用权重对 V **加权求和** → 得到融合上下文的 Token 表示 |

### 3.4 举例

句子「苹果 很 好吃」中，"好吃"跟谁最有关系？

```
Q_"好吃" × K_"苹果"  → 高分 ✅（形容词修饰名词）
Q_"好吃" × K_"很"    → 中分   （程度副词修饰形容词）
Q_"好吃" × K_"好吃"  → 低分   （自己不依赖自己）
                                ↓ softmax 归一化
 "苹果"权重 0.7, "很"权重 0.25, "好吃"权重 0.05
                                ↓ 加权 V 求和
 "好吃"的新表示 = 0.7×V_苹果 + 0.25×V_很 + 0.05×V_好吃
                            → 融合了整句话的上下文信息
```

## 四、多头注意力（Multi-Head Attention）

### 为什么需要多头

单头只看一种关系，多头可以**同时捕捉多种关系**：

```
头 1 → 主语-谓语关系     ("苹果" ↔ "吃")
头 2 → 修饰关系          ("很" ↔ "好吃")
头 3 → 指代关系          ("它" → "苹果")
头 4 → 句法距离关系       (长距离依赖)
...
头 8 → ...
```

### 计算方式

```
每个头有自己独立的 W_Q、W_K、W_V
    ↓
8 个头并行计算，各产出 1 个结果
    ↓
拼接 8 个结果
    ↓
再乘一个 W_O 降维 → 最终输出
```

> 多个头各有侧重，拼接后信息更全面。

## 五、Add & Norm 与前馈网络

### 5.1 Add（残差连接）

```
输出 = 输入 + Attention(输入)
```

**为什么**：防止原始信息在深层网络中丢失。即使注意力权重有偏差，原始 Token 信息仍保留。

### 5.2 Norm（层归一化）

```
将数值归一化到均值 0、方差 1
```

**为什么**：稳定数值范围，防止梯度爆炸/消失，让深层网络能训练。

### 5.3 前馈网络（Feed-Forward）

```
FFN(x) = ReLU(x × W₁ + b₁) × W₂ + b₂
```

两层全连接，中间有激活函数。**引入非线性变换**，增强模型表达能力。

> 注意力负责「沟通」（Token 之间交互），前馈负责「思考」（每个 Token 自身信息处理）。

## 六、编解码器架构

### 6.1 编码器（Encoder）

```
输入文本 → Token + 位置编码
    ↓
┌──────────────────┐
│  Multi-Head Self-Attention   │  ← 每个词看句子里所有词
│  Add & Norm                  │
│  Feed-Forward                │
│  Add & Norm                  │
└──────────────────┘  × N 层堆叠
    ↓
融合上下文的语义向量（送给解码器）
```

### 6.2 解码器（Decoder）

```
编码器输出
    ↓
┌──────────────────────────┐
│  Masked Multi-Head Self-Attention  │  ← 只能看左边的词（掩码）
│  Add & Norm                        │
│  Cross-Attention（Q来自解码器，K/V来自编码器）│  ← 参考输入文本
│  Add & Norm                        │
│  Feed-Forward                      │
│  Add & Norm                        │
└──────────────────────────┘  × N 层堆叠
    ↓
逐 Token 生成输出文本
```

### 6.3 三种主流变体

| 变体 | 结构 | 代表模型 | 用途 |
|------|------|---------|------|
| **Encoder-only** | 只用编码器 | BERT | 文本理解、分类、情感分析 |
| **Decoder-only** | 只用解码器 | GPT、DeepSeek、Llama、Claude | 文本生成、对话（当前主流） |
| **Encoder-Decoder** | 完整架构 | 原始 Transformer、T5 | 翻译、摘要（输入→输出） |

> 现在所有大语言模型都是 **Decoder-only** 变体。ChatGPT / DeepSeek / Claude 都是。

## 七、完整数据流

```
"我爱吃苹果"
    ↓ Tokenize
["我", "爱", "吃", "苹果"]
    ↓ Embedding + 位置编码
[v₁, v₂, v₃, v₄]   每个 v 是 768/4096 维向量
    ↓ Multi-Head Self-Attention（每个词融合上下文）
[V₁, V₂, V₃, V₄]   带上下文的向量
    ↓ Add & Norm
    ↓ Feed-Forward
    ↓ Add & Norm
    ↓ × N 层
    ↓ Linear + Softmax
预测下一个 Token: "，"
```

## 八、核心要点速查

| 组件             | 作用         | 一句话         |
| -------------- | ---------- | ----------- |
| Tokenization   | 文本 → Token | 把句子切成小块     |
| Embedding      | Token → 向量 | 给每个词赋予语义数字  |
| 位置编码           | 加入语序       | 告诉模型谁在前谁在后  |
| QKV            | 注意力输入      | Q问 K答 V给    |
| Self-Attention | 词间关联       | 每个词看到所有词    |
| Multi-Head     | 多角度关注      | 8 个头各学各的    |
| Add & Norm     | 保留+稳定      | 防止信息丢失和数值爆炸 |
| Feed-Forward   | 非线性变换      | 增强表达能力      |
| 堆叠 N 层         | 层层抽象       | 越深越聪明       |
